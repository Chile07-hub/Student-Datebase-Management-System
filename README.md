# Student Database Management System in C

## About the Project
The Student Database Management System is a menu-driven console application developed using C programming. It allows users to add, search, display, delete, sort, and update student records through a simple terminal interface.

### Features
1. Add new student records with unique student IDs
2. Search for a student using their ID
3. Display all student records in a structured table
4. Delete student records
5. Sort student records by ID using Bubble Sort
6. Update student name, address, and mobile number
7. Validate student IDs and mobile numbers

### Technologies Used
1. Programming Language: C
2. Header Files: stdio.h, string.h
3. Compiler: GCC
4. Version Control: Git and GitHub

### Concepts
1. Structures (struct)
2. Arrays and pointers
3. Functions
4. Loops and conditional statements
5. String handling
6. Input validation

### Current Limitations
1. Student records are stored in memory and are not saved after the program exits.
2. The application supports a maximum of 100 student records.
3. Email information and file-based storage are not currently implemented.

### Future Improvements
1. Add file handling to save student records permanently.
2. Improve validation when updating mobile numbers.
3. Add email information to student records.
